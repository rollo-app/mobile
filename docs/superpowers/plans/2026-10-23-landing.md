# Landing de Rollo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the text-only home of `rollo.juanifraga.com` with the approved "Papel" landing (7 sections, TestFlight CTA,
iPhone-only), move support to `/soporte`, and add scroll motion with a self-hosted, tree-shaken Motion.

**Architecture:** Everything stays a static build from `scripts/build-site.mjs` into `site/dist` (Cloudflare Workers assets).
The home's HTML/CSS moves to `scripts/site/home.mjs`; browser JS lives in `scripts/site/landing.js` and uses a Motion bundle
built by esbuild at site-build time. Tests run the build into a temp dir (as `scripts/__tests__/build-site.test.ts` already does)
and assert on the output files.

**Tech Stack:** Node ≥ 22.13 ESM scripts, `marked` (existing), `motion@14.0.0` + `esbuild@0.28.2` (new devDependencies),
`@resvg/resvg-js` (existing) for the OG image, Jest via `jest-expo` (existing).

**Spec:** `docs/superpowers/specs/2026-10-23-landing-design.md`

## Global Constraints

- Branch `feature/landing` from `develop`; commits in Spanish; PR to `develop` with CI green. Do **not** run `npm run site:deploy`
  without the owner's OK.
- Code, identifiers, comments and test descriptions in English; all visible copy in rioplatense Spanish with voseo, short, no "!",
  no inflated marketing.
- Colors: bg `#F2F0EB` / dark `#0E0F14`; tint `#3155F5` / dark `#5C7CFF`; tint only on actions (buttons, links) and selected state,
  never as fill. Reuse the existing `--fg/--muted/--rule` values from `build-site.mjs`.
- Type: headings `ui-serif,"New York",Georgia,serif`; body `-apple-system,BlinkMacSystemFont,"Helvetica Neue",sans-serif`. No
  downloaded fonts.
- No requests to third parties from any page: no CDNs, Google Fonts, analytics. Only outbound **links** allowed: the TestFlight URL,
  `mailto:`, and (appstore mode) the App Store URL.
- CTA text exactly **"Probar la beta en iPhone"** → `https://testflight.apple.com/join/Q557gZkR`; under it **"Solo para iPhone · Gratis"**.
- `/entrar`, `/privacidad`, `/terminos`, `404` keep their content; `/entrar` keeps its CSP, gets no new script/CSS.
- Mobile first from 360 px, 16 px side gutter, no horizontal scroll; AA contrast; visible focus; CTA ≥ 44 px tall; `lang="es"`.
- Motion: only `animate`, `scroll`, `inView`; bundle ≤ 30 000 bytes gzipped; no loops; Reduce Motion or no JS ⇒ final state (sharp photos).
- Mockups are stylized HTML/CSS in the paper palette, never fake screenshots. Map = abstract land/water/roads + initial pins.
- Design references: skills `ui-ux-pro-max` and `frontend-design`; Rollo's identity overrides their palettes/fonts.

## Review Focus

- **No JS / Reduce Motion:** every section's text and photos visible and sharp → head-script test in Task 4 + manual check in Task 6.
- **360 px phone:** no horizontal scroll, hero phone mockup stacks under the text → `scrollWidth` check in Task 6.
- **Dark mode:** cobalt CTA and muted text keep AA contrast on `#0E0F14` → contrast check in Task 6.
- **Old support link `/#soporte`** (App Store Connect still points there until the owner changes it) lands on a support link → test in Task 1.
- **`/entrar` untouched by the new JS** (its CSP would block it and the token page must stay inert) → test in Task 4.

## File Structure

- Modify `scripts/build-site.mjs` — constants (`SITE_URL`, store config), writes `/soporte`, home from `home.mjs`, copies assets, runs the Motion bundle.
- Create `scripts/site/home.mjs` — `homeHtml(opts)` and `homeCss`: the 7 sections and their mockups.
- Create `scripts/site/mockups.mjs` — small functions returning the phone mockup HTML for each section.
- Create `scripts/site/motion-entry.mjs` — `export { animate, scroll, inView } from "motion";`
- Create `scripts/site/landing.js` — browser script (section entrance + reveal on scroll).
- Create `scripts/build-og.mjs` + commit `scripts/site/og.png` (1200×630).
- Modify `package.json` — devDeps `motion@14.0.0`, `esbuild@0.28.2`; script `"og": "node scripts/build-og.mjs"`.
- Create `scripts/__tests__/landing.test.ts` — tests for home, `/soporte`, assets. Keep `build-site.test.ts` as is (plus one assertion in Task 4).
